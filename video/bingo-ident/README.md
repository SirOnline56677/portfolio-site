# Bingo AI ident (Remotion source)

Source for `public/work/bingo-ai-job-matching-platform-for-seniors/bingo-ident.mp4`
and its poster: the 10s ident — photo slideshow burst resolving into the
"Bingo" wordmark with the disc animation, held to the end.

Compositions: `Square` (1080×1080, what the homepage card uses, rendered at
0.6667 scale → 720), plus `Vertical` (1080×1920) and `Wide` (1920×1080).

```bash
npm install
npm run render   # writes bingo-ident.mp4 into the site's public folder
npm run still    # writes the poster (mid-hold wordmark, frame 150)
```
